# Luwas features

Disaster reporting for citizens. Command desk for barangay officers.

Home area: Brgy. Nangka, Consolacion, Cebu. Other barangays can be added (e.g. Brgy. Apas, Cebu City).

---

## For citizens

- Report a hazard or ask for help (yourself or someone else)
- Photo required; voice note optional
- No login needed; you get a reference ID to track the report
- Optional account with ID check and household match
- English, Filipino, and Cebuano
- Works on web and iOS

---

## For officers

- Log in and switch between onboarded barangays
- Map of incidents, households, and hazards
- Board of open reports; assign who handles each one
- Review queue: accept, reject, or hold for more review
- Household roster and staff list
- SMS, email, and voice alerts when a report is confirmed
- Add a new barangay (hall location + profile)

---

## AI checks

- Photo + text scored before an officer decides
- ID and selfie check when someone registers
- Chat helper for officers (weather, roster, triage)
- Still works with simple rules if AI is down
- Trust score from account, contacts, and AI confidence

---

## Map and weather

- Live map for officers and public view
- Flood / slope layers from Earth Engine caches
- Weather from Google or Open-Meteo
- Evacuation / hall points on the map

---

## Behind the scenes

- Firebase for login, live data, and photo storage
- App hosted at luwasph.com
- Optional BigQuery copy of finished reports

---

## Demo mode (optional)

When simulation is on: typhoon scenario packs, demo logins, and sample reports for Cup demos. Turn off for live ops.
